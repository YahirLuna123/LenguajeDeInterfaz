# Lenguaje de Interfaz — Prácticas 

**Instituto Tecnológico de Culiacán**  
**Carrera:** Ingeniería en Sistemas Computacionales  
**Materia:**Lenguaje de Interfaz  
**Horario:** 10:00-11:00
**Profesor:** M.C. José Luis Medina Jiménez  


---

1. **Práctica 1:** *Ciclos numéricos*  
   - Implementación de ciclos de repetición contados mediante el registro `ECX` e instrucción `LOOP`.
2. **Práctica 2:** *Captura y desplegado de mensaje*  
   - Lectura de cadenas desde la consola mediante `ReadString` y almacenamiento dinámico en buffers de memoria.
3. **Práctica 3:** *Comparación y prueba*  
   - Uso de la instrucción `CMP` y saltos condicionales (`JGE`) para la evaluación de banderas lógicas.
4. **Práctica 4:** *Saltos*  
   - Control de flujo del programa utilizando saltos incondicionales (`JMP`).
5. **Práctica 4.1:** *Mayor, menor o igual con entrada del usuario*  
   - Captura de datos de usuario con `ReadInt` y evaluación de tres vías mediante `JG`, `JL` y `JE`.
6. **Práctica 5:** *Condicionales*  
   - Operación lógica `TEST` y evaluación de banderas sin modificación de operandos para determinar paridad.
7. **Práctica 5.1:** *Repetir hasta que el usuario ingrese 0*  
   - Estructura de ciclo interactivo centinela con interrupción mediante condición de parada igual a cero.
8. **Práctica 6:** *Decremento e Incremento*  
   - Modificación directa de registros numéricos utilizando las instrucciones `INC` y `DEC`.
9. **Práctica 6.2:** *Contador de ocupación de un estacionamiento*  
   - Aplicación práctica para el control de aforo mediante incrementos y decrementos condicionales.
10. **Práctica 7:** *Validación de formato*  
    - Verificación y análisis de sintaxis o rangos de entrada en cadenas/caracteres.
11. **Práctica 8:** *Operaciones aritméticas*  
    - Suma, resta, multiplicación y división de enteros utilizando los registros de propósito general.
12. **Práctica 9:** *PUSH y POP*  
    - Manejo directo de la pila (*Stack*) para la preservación de estado de registros e inversión de datos.
13. **Práctica 10:** *Cadena con decimal*  
    - Lectura y despliegue de valores en formato de punto flotante utilizando el coprocesador (`ReadFloat` / `WriteFloat`).
14. **Práctica 11:** *Operaciones lógicas*  
    - Manejo de compuertas a nivel de bits utilizando `AND`, `OR` y `XOR` para manipulación de máscaras.
15. **Práctica 12:** *Desplazamiento y rotación*  
    - Manipulación binaria mediante desplazamiento de bits (`SHL`, `SHR`) y rotaciones (`ROL`).
16. **Práctica 13:** *String hexadecimal*  
    - Entrada y salida de datos numéricos en base 16 mediante `ReadHex` y `WriteHex`.
17. **Práctica 14:** *Captura y almacenamiento de datos numéricos*  
    - Captura de números por teclado y su persistencia en variables de la sección `.data`.
18. **Práctica 15:** *Manipulación de datos*  
    - Transferencia, copia e indexación de bloques de datos en memoria entre arreglos fuente y destino.
